# Colorful Trash Game

Colorful Trash Game is a gamified educational application designed to teach children how to sort waste correctly. The app uses category-based learning videos, timed drag-and-drop activities, quizzes, rewards, and fun facts to make waste education interactive and engaging.

## About the Project

This project was developed to help children learn proper waste segregation in a simple and enjoyable way. It focuses on making environmental education more interactive through gameplay and structured learning activities.

The application introduces children to different waste categories and helps them understand where common waste items belong. It combines visual learning, practice-based interaction, and quiz reinforcement to support better understanding.

## Project Objective

The main objective of this project is to improve children's awareness of waste segregation through a gamified learning experience.

## Features

- Interactive home screen
- Learn to Sort Waste module
- Waste category selection
- Mandatory educational videos for each category
- Pause option during video playback
- Timed drag-and-drop waste sorting game
- Score tracking for correct answers
- Instant feedback for each drop
- Repeat-until-correct game flow
- Quiz section with 2 questions per category
- Wrong-answer explanations
- Correct-answer reveal after repeated wrong attempts
- Reward screen after completing all categories
- Fun fact shown with the reward
- Additional rapid game mode through **Play Another Fun Game**

## Waste Categories

The app includes the following waste categories:

- Wet/Organic Waste
- Dry/Recyclable Waste
- Domestic Hazardous Waste

## How the Project Works

1. The user starts on the home screen.
2. The user clicks **Learn to Sort Waste**.
3. The user is taken to the category selection screen.
4. The user selects one waste category.
5. After selecting a category, an educational video starts automatically.
6. The video cannot be skipped, but it can be paused if needed.
7. The child must watch the full video before moving forward.
8. After the video ends, the user continues to the drag-and-drop game.
9. In the game, waste items must be dropped into the correct bin within **10 seconds**.
10. The app gives a score for each correct drop and shows instant feedback such as **Good!**
11. If all 3 items are sorted correctly, the user moves to the quiz.
12. If all items are not correct, the game repeats until the user gets all 3 correct.
13. After the game, the quiz begins.
14. Each category contains **2 quiz questions**.
15. The **Next** button does not appear until the correct answer is selected.
16. The user gets up to **3 chances** to answer each question.
17. For every wrong answer, the app explains which type of waste the item belongs to.
18. If the user still gets it wrong after repeated attempts, the correct answer is revealed.
19. The user must complete all categories.
20. After completing all categories, the user unlocks a reward screen.
21. The reward includes a title such as **Sorting Star!** and a fun fact.
22. The user can return to the home screen.
23. The user can also choose **Play Another Fun Game**, which is a rapid round containing only the game and quiz.

## Rewards

After completing Level 1 in all categories, the user unlocks a reward screen.

Example reward:

The reward screen also includes a fun environmental fact to make learning more enjoyable and memorable.
